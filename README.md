# آموزش پایتون ویژه زیست‌شناسان

این ریپوزیتوری یک آموزش پایتون ساده و کاربردی است که مخصوص زیست‌شناسان طراحی شده است. مطالب با زبانی ساده و به سبک زیست‌شناسی ارائه شده تا یادگیری پایتون برای دانشجویان و پژوهشگران این حوزه آسان‌تر شود.

## درباره محتوا
- آموزش‌ها در قالب نوت‌بوک پایتون نوشته شده‌اند.
- مثال‌ها با تم و مفاهیم زیست‌شناسی سازگار شده‌اند.
- هدف این است که پایتون را به صورت عملی و در زمینه زیست‌شناسی آموزش دهیم.

## ویژگی‌های این ریپو
- همراه با آموزش تصویری
- فیلم ضبط شده به زبان فارسی
- مناسب برای مبتدیان در پایتون و زیست‌شناسی

## نحوه استفاده
1. نوت‌بوک‌ها را باز کنید.
2. هر سلول را اجرا کنید تا نتایج را ببینید.
3. همراه با فیلم آموزشی، مفاهیم را مرحله به مرحله دنبال کنید.

## هدف
این مجموعه برای زیست‌شناسانی تهیه شده که می‌خواهند پایتون را برای تحلیل داده و خودکارسازی فرآیندها یاد بگیرند، اما تجربه قبلی کمی یا هیچ تجربه‌ای در برنامه‌نویسی ندارند.
